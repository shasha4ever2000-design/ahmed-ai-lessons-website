You do not need to be a data analyst. If you can keep a clean list of sales or expenses in Excel, you can build your first report in one sitting.</p><p class="prose__intro">This lesson uses a made-up sales file for a small company with three branches. You will load it, check it, write one simple measure and build one page. Menu names were checked in October 2026 on Microsoft Learn. Power BI changes often, so if a button has moved, look for the same words.</p></div><section id="get-ready" class="prose lesson-section" aria-labelledby="get-ready-h"><h2 id="get-ready-h" class="lesson-h2">Get Power BI Desktop and a tidy Excel file</h2><p>Power BI Desktop is the free app you build reports in. It runs on Windows (Windows 10 or later). Get it from Microsoft directly, not from other download sites.</p><ol class="steps"><li><span class="steps__n" aria-hidden="true">1</span><span>Open the Microsoft Store and search for Power BI Desktop, or go to the Power BI Desktop page in the Microsoft Download Center. Both are official and free.</span></li><li><span class="steps__n" aria-hidden="true">2</span><span>Install it and open it. You build and save reports on your own computer. Sharing them is a separate step, covered at the end of this lesson.</span></li><li><span class="steps__n" aria-hidden="true">3</span><span>Tidy your Excel file: one header row, one row per sale, no merged cells, no total rows in the middle, and dates stored as real dates.</span></li><li><span class="steps__n" aria-hidden="true">4</span><span>Save the file somewhere it will stay. Power BI connects to the file in that place, so if you move it later you will need to point Power BI to the new location.</span></li></ol><p>For this lesson, picture a sheet called Sales with four columns of made-up data:</p><ul class="prose-list"><li>Date: the day of the sale, for example 5 January 2026.</li><li>Branch: North, Coast or Central (all made up).</li><li>Category: Chairs, Desks or Paper.</li><li>Amount: the sale in SAR, for example 1,200 or 450.</li></ul><aside class="callout callout--tip"><p class="callout__title">Make it a named Excel table first</p><p>In Excel, turn the list into a proper table and give it a clear name such as Sales. Power BI lists named tables when you connect, so you pick the right data the first time.</p></aside></section><section id="load-and-check" class="prose lesson-section" aria-labelledby="load-and-check-h"><h2 id="load-and-check-h" class="lesson-h2">Load the file and check it in Power Query</h2><p>Do not load the data straight away. Two minutes of checking now protects you from a wrong total later.</p><ol class="steps"><li><span class="steps__n" aria-hidden="true">1</span><span>On the Home ribbon, select Get data, then choose Excel workbook. Find your file and select Open.</span></li><li><span class="steps__n" aria-hidden="true">2</span><span>In the Navigator window, tick the Sales table. Select Transform Data instead of Load. The Power Query Editor opens.</span></li><li><span class="steps__n" aria-hidden="true">3</span><span>Look at the small icon on the left of each column heading. It shows the data type. Date should be a date, Amount should be a number, and Branch and Category should be text.</span></li><li><span class="steps__n" aria-hidden="true">4</span><span>If a type is wrong, select that icon and pick the right one, for example Date, or Fixed decimal number for money.</span></li><li><span class="steps__n" aria-hidden="true">5</span><span>To drop blank rows, open the filter arrow on the Amount column and choose Remove empty. This removes rows where Amount is null or blank.</span></li><li><span class="steps__n" aria-hidden="true">6</span><span>On the Home tab, select Close &amp; Apply. Your clean table loads into Power BI.</span></li></ol><aside class="callout callout--warn"><p class="callout__title">Amounts stored as text won't add up</p><p>If Amount comes in as text, Power BI cannot total it. Fix the type in Power Query before you build anything, then compare a few values with your Excel file.</p></aside></section><section id="first-measure" class="prose lesson-section" aria-labelledby="first-measure-h"><h2 id="first-measure-h" class="lesson-h2">Write your first measure, with AI as a helper</h2><p>A measure is a small named calculation written in DAX, the formula language of Power BI. Power BI can add up a number column on its own, but a named measure is clearer and you can reuse it in every visual.</p><ol class="steps"><li><span class="steps__n" aria-hidden="true">1</span><span>On the Home ribbon, select New measure. A formula bar opens above the report canvas.</span></li><li><span class="steps__n" aria-hidden="true">2</span><span>Replace the word Measure with this line, then press Enter: Total Sales = SUM(Sales[Amount])</span></li><li><span class="steps__n" aria-hidden="true">3</span><span>The new measure appears in the Data pane on the right, inside the Sales table.</span></li></ol><p>For anything harder, ask a chat assistant such as ChatGPT or Claude. Keep real figures, customer names and company files out of public chat tools. Then test the measure: the total on your card should match a SUM of the same column in Excel.</p></aside></section><section id="build-the-page" class="prose lesson-section" aria-labelledby="build-the-page-h"><h2 id="build-the-page-h" class="lesson-h2">Build one page: three visuals and a slicer</h2><p>Start with a few visuals, each answering one clear question. Before you add a new visual, click an empty part of the canvas, so you do not change the one you just made.</p><div class="table-wrap" role="region" aria-label="Which visual answers which question" tabindex="0"><table role="table"><caption>Which visual answers which question</caption><thead role="rowgroup"><tr role="row"><th scope="col" role="columnheader">Question</th><th scope="col" role="columnheader">Visual</th><th scope="col" role="columnheader">What to put in it</th></tr></thead><tbody role="rowgroup"><tr role="row"><th scope="row" role="rowheader">What is the total?</th><td role="cell" dir="auto">Card</td><td role="cell" dir="auto">Total Sales in Values</td></tr><tr role="row"><th scope="row" role="rowheader">Which category sells most?</th><td role="cell" dir="auto">Bar chart</td><td role="cell" dir="auto">Category and Total Sales</td></tr><tr role="row"><th scope="row" role="rowheader">How are sales moving month by month?</th><td role="cell" dir="auto">Line chart</td><td role="cell" dir="auto">Date on the X-axis, Total Sales on the Y-axis</td></tr><tr role="row"><th scope="row" role="rowheader">How does one branch look on its own?</th><td role="cell" dir="auto">Slicer</td><td role="cell" dir="auto">Branch</td></tr></tbody></table></div><ol class="steps"><li><span class="steps__n" aria-hidden="true">1</span><span>Card: in the Visualizations pane, on the Build visual tab, select Card. Drag Total Sales from the Data pane into Values.</span></li><li><span class="steps__n" aria-hidden="true">2</span><span>Bar chart: select one of the bar chart icons, then select Category and Total Sales in the Data pane.</span></li><li><span class="steps__n" aria-hidden="true">3</span><span>Line chart: select Line chart. Put Date on the X-axis and Total Sales on the Y-axis.</span></li><li><span class="steps__n" aria-hidden="true">4</span><span>If the line shows single days, select the arrow next to Date in the X-axis well, choose Date Hierarchy, then keep only Year and Month.</span></li><li><span class="steps__n" aria-hidden="true">5</span><span>Slicer: select Slicer, then Branch in the Data pane. Under Style, Dropdown saves space and Tile is easy to tap.</p></aside></section><section id="copilot-and-sharing" class="prose lesson-section" aria-labelledby="copilot-and-sharing-h"><h2 id="copilot-and-sharing-h" class="lesson-h2">Copilot and sharing: what you need first</h2><p>Copilot in Power BI can help you create and edit report pages, summarize your data model, write and explain DAX queries, and add descriptions to measures. For DAX, open DAX query view in Power BI Desktop and select the Copilot button. Copilot needs the right setup in your organization, so check these points first:</p><ul class="prose-list"><li>A paid Fabric capacity (F2 or higher) or Power BI Premium (P1 or higher). Trial capacities and free options are not supported.</li><li>A Power BI Pro or Premium Per User licence on its own is not enough.</li><li>In Power BI Desktop, you need write access to a workspace on that capacity.</li><li>Your admin has not switched Copilot off. It is on by default, but admins can turn it off or limit who can use it.</li></ul><p>Sharing is a separate step. When your page is ready:</p><ol class="steps"><li><span class="steps__n" aria-hidden="true">1</span><span>On the Home ribbon, select Publish.</span></li><li><span class="steps__n" aria-hidden="true">2</span><span>Sign in with a work or school account. Personal addresses such as Gmail or Hotmail cannot sign up for the Power BI service directly.</span></li><li><span class="steps__n" aria-hidden="true">3</span><span>Pick a workspace, such as My workspace, and choose Select.</span></li></ol><p>What happens next depends on your licence. A free licence lets you use the Power BI service for your own reports, but not share them. To share with colleagues, you and they normally need a paid licence such as Power BI Pro. The exception is a workspace on Power BI Premium or Fabric F64 (or higher) capacity, where free users can be given access.</p><aside class="callout callout--warn"><p class="callout__title">Ask IT before you share</p><p>Your company decides the licences, the capacity and who can see what. Check with your IT team or Power BI admin before you publish anything with real figures.</p></aside></section><section id="mistakes" class="lesson-section" aria-labelledby="mistakes-h"><h2 id="mistakes-h" class="lesson-h2">Common mistakes</h2><ul class="mistakes" role="list"><li class="mistakes__item"><p class="mistakes__title">Loading without checking</p><p>If Amount loads as text, or blank rows stay in, your totals are wrong from the start. Use Transform Data and check the types first.</p></li><li class="mistakes__item"><p class="mistakes__title">Too many visuals on one page</p><p>A page with a dozen charts answers nothing. Start with a total, one comparison and one trend.</p></li><li class="mistakes__item"><p class="mistakes__title">Trusting DAX without testing it</p><p>A measure from AI can look right and still count the wrong thing. Compare it with a quick total in Excel before you share.</p></li></ul></section><section id="practice" class="lesson-section practice" aria-labelledby="practice-h"><h2 id="practice-h" class="lesson-h2">Try it now: 5 minutes</h2><p>Try it with a real task from your week. Keep this page open in another tab.</p><ol class="steps"><li><span class="steps__n" aria-hidden="true">1</span><span>Make a small Excel table of made-up sales for two or three months: a date, a branch, a category and an amount.</span></li><li><span class="steps__n" aria-hidden="true">2</span><span>Load it with Get data, check the types in Power Query, remove empty rows, and select Close &amp; Apply.</span></li><li><span class="steps__n" aria-hidden="true">3</span><span>Create the Total Sales measure, then build the card, the bar chart, the line chart and a branch slicer.</span></li><li><span class="steps__n" aria-hidden="true">4</span><span>Ask ChatGPT or Claude for one more measure using only your table and column names, then check it against Excel.</span></li></ol></section><figure class="takeaway"><p class="small-title">Remember this</p><blockquote><p>Clean table in, types checked, one measure, three visuals and a slicer. Let AI draft the DAX, and check every number against your Excel file.</p></blockquote></figure>
